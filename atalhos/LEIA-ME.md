# Atalhos para abrir o EduCAD como aplicativo

Estes atalhos abrem o EduCAD **sem abas, barra de endereços nem barras de ferramentas**, ocupando a tela inteira. São indicados para os computadores do laboratório.

1. Abra o arquivo desejado num editor de texto e troque `https://SEU-USUARIO.github.io/educad/` pelo endereço do seu GitHub Pages. Também serve um caminho local, como `file:///C:/EduCAD/index.html`.
2. Copie o arquivo para a Área de Trabalho (Windows: `.bat`; Linux: `educad.desktop`, dando permissão de execução).

| Arquivo | Resultado | Como sair |
|---|---|---|
| `EduCAD - janela de aplicativo (Edge/Chrome).bat` | Janela de aplicativo em tela cheia | F11 sai da tela cheia; Alt+F4 fecha |
| `EduCAD - modo quiosque (Edge).bat` | Tela cheia travada, sem nenhum elemento do navegador (avaliações) | Alt+F4 |
| `educad.desktop` | Igual à janela de aplicativo, no Linux | F11 / Alt+F4 |

Observações:
- O navegador precisa estar **totalmente fechado** antes de usar o atalho; caso contrário, ele pode abrir uma aba comum.
- No modo quiosque, o aluno não consegue trocar de site pela interface do navegador.
- A alternativa sem atalhos é **instalar o EduCAD** pelo botão "⬇ Instalar" (Chrome ou Edge, a partir do GitHub Pages). Ele passa a ter ícone próprio e janela própria, como um programa instalado.
